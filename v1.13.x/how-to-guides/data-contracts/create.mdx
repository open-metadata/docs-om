# Create Data Contract

Data contracts are currently available for tables ingested into OpenMetadata. The following guide shows how a data contract was created for a snowflake.DEMO_STAGE.JAFFLE_SHOP.CUSTOMERS table.

To create a Data Contract for a table in OpenMetadata:

1. On the table's page, click **Contract**.
2. Click **+ Add Contract**.

    <img src="/public/images/how-to-guides/contracts/create1.png" alt="Adding a Data Contract to an OpenMetadata Table" />

3. On the **Contract Details** tab, do the following:
    1. Enter a name for the data contract.
    2. Optional: Add **Owners** and a **Description**.

    <img src="/public/images/how-to-guides/contracts/create2.png" alt="Adding Contract Details" />

4. On the **Schema** tab, select the columns of the table to add to the data contract, or select all columns with the checkbox at the top right.

    <img src="/public/images/how-to-guides/contracts/create3.png" alt="Selecting a schema for an OpenMetadata Data Contract" />

5. On the **Semantics** tab, add the business rules to enforce. For tables, rules can be created for:
    - Identity fields: **Service**, **Owners**, **Display Name**, **Name**
    - Classification fields: **Description**, **Tags**, **Domain**, **Data Product**, **Tier**

    <img src="/public/images/how-to-guides/contracts/create4.png" alt="Adding rules to an OpenMetadata Data Contract" />

6. Optional: Click **+ Add New Rule** to create more rules.

    <img src="/public/images/how-to-guides/contracts/create5.png" alt="Adding more rules to an OpenMetadata Data Contract" />

7. On the **Quality** tab, click **+ Add Test** to add a [Data Quality Test](https://docs.open-metadata.org/latest/how-to-guides/data-quality-observability/quality/test) or tests to the contract.

    <img src="/public/images/how-to-guides/contracts/create6.png" alt="Adding data quality tests to an OpenMetadata Data Contract" />

8. Click **Save**.

9. To run the new contract, open the actions menu and select **Run now**.

    <img src="/public/images/how-to-guides/contracts/create7.png" alt="Running an OpenMetadata Data Contract" />
