# Java SDK

We now present a high-level Java API as a type-safe and gentle wrapper for the OpenMetadata backend.

The open-source OpenMetadata SDK for Java simplifies provisioning, managing, and using OpenMetadata resources from the Java application code. \
The OpenMetadata SDK for Java libraries build on top of the underlying OpenMetadata REST API, allows you to use those APIs through familiar Java paradigms. However, you can always use the REST API directly from Java code, if you prefer to do so.

You can find the source code for the OpenMetadata libraries in the [GitHub repository](https://github.com/open-metadata/OpenMetadata/tree/main/openmetadata-sdk). As an open-source project, contributions are always welcome!

You can add the below Maven Dependency for the OpenMetadata Java SDK.

```xml
<dependency>
  <groupId>org.open-metadata</groupId>
  <artifactId>openmetadata-sdk</artifactId>
  <version>1.13.6</version>
</dependency>
```


## Connect to the OpenMetadata Server

To connect to your OpenMetadata server, you need:

* Server URL: The URL where your OpenMetadata instance is running, ending in `/api`. For example, `http://localhost:8585/api`.
* Access token: A JWT token for a user or bot. See [Authentication](/v1.13.x/api-reference/authentication) to learn how to get one.

```java
import org.openmetadata.sdk.client.OpenMetadataClient;
import org.openmetadata.sdk.config.OpenMetadataConfig;

OpenMetadataConfig config = OpenMetadataConfig.builder()
    .serverUrl("http://localhost:8585/api")
    .accessToken("{jwt_token}")
    .build();

OpenMetadataClient client = new OpenMetadataClient(config);
```

You can also tune the connection. Timeouts are in milliseconds, and `header` adds a custom header to every request:

```java
OpenMetadataConfig config = OpenMetadataConfig.builder()
    .serverUrl("http://localhost:8585/api")
    .accessToken("{jwt_token}")
    .connectTimeout(10000)
    .readTimeout(30000)
    .header("X-Request-Source", "my-app")
    .build();
```

## Authentication

The Java SDK authenticates with a JWT access token that you pass to `accessToken(...)`. This is the same for every sign-in method on your OpenMetadata server, including Google, Okta, Auth0, Azure, and custom OIDC. Generate a bot token or a personal access token in OpenMetadata and use it here.

If your server does not require authentication, leave out `accessToken(...)`.

## Use the Fluent API

The fluent classes, such as `Tables`, `Users`, and `Teams`, work with a default client. Register your client once with `OM.init`, and the fluent classes use it:

```java
import org.openmetadata.sdk.OM;
import org.openmetadata.sdk.fluent.Tables;

OM.init(client);

// Find a table by its fully qualified name
var table = Tables.findByName("mysql-prod.employees.public.employees")
    .includeOwners()
    .includeTags()
    .fetch()
    .get();

// Update its description
Tables.findByName("mysql-prod.employees.public.employees")
    .fetch()
    .withDescription("Updated description")
    .save();
```

## Use the Service Clients

Every entity type has a service on the client, such as `client.tables()`, `client.users()`, and `client.dashboards()`. These services offer the same methods: `create`, `get`, `getByName`, `list`, `update`, `delete`, and `restore`. Below are some examples:

```java
import org.openmetadata.sdk.models.ListParams;

// Tables
var tables = client.tables().list(new ListParams().setLimit(10));
for (var table : tables.getData()) {
    System.out.println(table.getFullyQualifiedName());
}

// Users
var users = client.users().list(new ListParams().setLimit(10));

// Dashboards
var dashboards = client.dashboards().list(new ListParams().setLimit(10));
```

Please refer to the examples to access an API:

* Create a table

```java
import java.util.List;
import org.openmetadata.schema.api.data.CreateTable;
import org.openmetadata.schema.type.Column;
import org.openmetadata.schema.type.ColumnDataType;

CreateTable request = new CreateTable()
    .withName("orders")
    .withDatabaseSchema("mysql-prod.employees.public")
    .withDescription("Orders placed by customers")
    .withColumns(List.of(
        new Column()
            .withName("order_id")
            .withDataType(ColumnDataType.BIGINT)
            .withDescription("Primary key"),
        new Column()
            .withName("status")
            .withDataType(ColumnDataType.VARCHAR)
            .withDataLength(50)));

var table = client.tables().create(request);
```

* Get a table by fully qualified name

```java
var table = client.tables().getByName("mysql-prod.employees.public.employees", "columns,owners");
```

* Search

```java
String response = client.search()
    .query("customer")
    .index("table_search_index")
    .size(10)
    .execute();
```

The search call returns the raw JSON response from the server as a string.

## Handle Errors

When the server returns an error, the SDK throws an `OpenMetadataException`. Use `getStatusCode()` to see which error it was:

```java
import org.openmetadata.sdk.exceptions.OpenMetadataException;

try {
    var table = client.tables().getByName("mysql-prod.employees.public.missing");
} catch (OpenMetadataException e) {
    if (e.getStatusCode() == 404) {
        System.out.println("Table not found");
    } else {
        System.out.println("Request failed: " + e.getMessage());
    }
}
```
