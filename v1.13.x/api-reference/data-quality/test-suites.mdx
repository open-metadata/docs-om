# Test Suites

A **Test Suite** is a collection of test cases. Test suites come in two types.

## Basic vs Logical

The `basic` response field identifies the suite type:

| Type | `basic` | Description |
|------|-------------|-------------|
| **Basic** | `true` | Automatically created and tied to a specific table. Contains all test cases for that table. |
| **Logical** | `false` | User-defined grouping of test cases across multiple tables for organized reporting. |

<Info>
Basic test suites are automatically created when you add the first test case to a table. Logical test suites are created manually to group related tests across tables.
</Info>

## Fully Qualified Name

The fully qualified name (FQN) for a test suite is its name:

```
critical_data_quality_checks
```
