# Update an API Collection

Create an API collection or update it if it already exists, using `PUT /v1/apiCollections` with the full request body. Send the complete definition, not just the fields you want to change. To change only some fields, use `PATCH` with a JSON Patch array and the `application/json-patch+json` content type, as shown in the PATCH examples below.

## Body Parameters

<ParamField body="name" type="string" required>
  Name of the API collection. Must be unique within the parent API service.
</ParamField>

<ParamField body="service" type="string" required>
  Fully qualified name of the parent APIService, for example `sample_api_service`.
</ParamField>

<ParamField body="endpointURL" type="string">
  Base URL for the API collection, for example `https://petstore3.swagger.io/#/pet`.
</ParamField>

<ParamField body="displayName" type="string">
  Human-readable display name for the API collection.
</ParamField>

<ParamField body="description" type="string">
  Description of the API collection in Markdown format.
</ParamField>

<ParamField body="owners" type="array">
  Array of owner references (users or teams) to assign to the API collection.

  <Expandable title="properties">
    <ParamField body="id" type="string">
      UUID of the owner entity.
    </ParamField>

    <ParamField body="type" type="string">
      Type of owner entity, for example `user`, `team`.
    </ParamField>

    <ParamField body="name" type="string">
      Name of the owner entity.
    </ParamField>
  </Expandable>
</ParamField>

<ParamField body="domains" type="array">
  Fully qualified names of the domains to assign for governance purposes.
</ParamField>

<ParamField body="tags" type="array">
  Array of classification tags to apply to the API collection.

  <Expandable title="properties">
    <ParamField body="tagFQN" type="string" required>
      Fully qualified name of the tag.
    </ParamField>

    <ParamField body="labelType" type="string">
      Type of label, for example `Manual`, `Derived`, `Propagated`.
    </ParamField>

    <ParamField body="state" type="string">
      State of the tag, for example `Suggested`, `Confirmed`.
    </ParamField>
  </Expandable>
</ParamField>

<ParamField body="extension" type="object">
  Custom property values defined by your organization's metadata schema.
</ParamField>

<RequestExample dropdown>
```bash PUT /v1/apiCollections
curl -X PUT "{base_url}/api/v1/apiCollections" \
  -H "Authorization: Bearer {access_token}" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "pet",
    "service": "sample_api_service",
    "endpointURL": "https://petstore3.swagger.io/#/pet",
    "description": "Pet-related API endpoints"
  }'
```

```python PATCH /v1/apiCollections/{id}
from metadata.sdk import configure
from metadata.sdk.entities import APICollections

configure(
    host="https://your-company.open-metadata.org/api",
    jwt_token="your-jwt-token"
)

# Retrieve, modify, and update
ac = APICollections.retrieve("0f7ee81c-8163-4097-8adb-45c3d6c7b14b")
ac.description = "Updated: Pet-related API endpoints for the Petstore service"
updated = APICollections.update(ac)

print(f"Updated to version {updated.version.root}")
```

```java PATCH /v1/apiCollections/{id}
import org.openmetadata.schema.entity.data.APICollection;

// client is an initialized OpenMetadataClient.

// Retrieve, modify, and update
APICollection ac = client.apiCollections().get("0f7ee81c-8163-4097-8adb-45c3d6c7b14b");
ac.setDescription("Updated: Pet-related API endpoints for the Petstore service");
APICollection updated = client.apiCollections().update("0f7ee81c-8163-4097-8adb-45c3d6c7b14b", ac);
```

```bash PATCH /v1/apiCollections/{id}
# Update by ID
curl -X PATCH "{base_url}/api/v1/apiCollections/0f7ee81c-8163-4097-8adb-45c3d6c7b14b" \
  -H "Authorization: Bearer {access_token}" \
  -H "Content-Type: application/json-patch+json" \
  -d '[
    {"op": "replace", "path": "/description", "value": "Updated: Pet-related API endpoints for the Petstore service"}
  ]'

# Update by name
curl -X PATCH "{base_url}/api/v1/apiCollections/name/sample_api_service.pet" \
  -H "Authorization: Bearer {access_token}" \
  -H "Content-Type: application/json-patch+json" \
  -d '[
    {"op": "replace", "path": "/description", "value": "Updated: Pet-related API endpoints for the Petstore service"}
  ]'
```

## Returns

Returns the updated API collection object with the new version number.

## Response

<ResponseField name="id" type="string">
  Unique identifier for the API collection (UUID format).
</ResponseField>

<ResponseField name="name" type="string">
  API collection name.
</ResponseField>

<ResponseField name="fullyQualifiedName" type="string">
  Fully qualified name in format `service.collectionName`.
</ResponseField>

<ResponseField name="description" type="string">
  Updated description.
</ResponseField>

<ResponseField name="version" type="number">
  Incremented version number.
</ResponseField>

## Error Handling

| Code | Error Type | Description |
|------|-----------|-------------|
| `400` | `BAD_REQUEST` | Invalid or malformed request body |
| `401` | `UNAUTHORIZED` | Invalid or missing authentication token |
| `403` | `FORBIDDEN` | User lacks permission to update this API collection |
| `409` | `CONFLICT` | Concurrent modification detected |
