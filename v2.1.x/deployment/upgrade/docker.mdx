# Upgrade on Docker

To run OpenMetadata with Docker, you can simply download the `docker-compose.yml` file. Optionally, we added some
Named Volumes to handle data persistence.

<Tip>

You can find more details about Docker deployment [here](/v2.1.x/deployment/docker)

</Tip>

Below we have highlighted the steps needed to upgrade to the latest version with Docker.

<UpgradePrerequisites />

## Upgrade Process

<Steps>
  <Step title="Stop the Running Deployment">
    Stop the running Docker Compose deployment:

    ```bash
    docker compose down
    ```
  </Step>
  <Step title="Replace the Docker Compose File">
    Download the Docker Compose service file from the [OpenMetadata GitHub releases page](https://github.com/open-metadata/OpenMetadata/releases/latest), then replace your existing file with it.

    <Note>
    If you run the Resource Description Framework (RDF) store from the OpenMetadata Docker Compose files, the 2.1 file uses a new Fuseki image. It also has new
    settings and a new data volume. The old volume is not reused, so the new store starts empty. Read the Fuseki
    changes before you replace the file. For more information, see
    [Data Governance](/v2.1.x/deployment/upgrade/breaking-changes/data-governance#the-bundled-fuseki-rdf-store-image-changed).
    </Note>

    <Note>
    The OpenMetadata server image now runs as user `65532`. If you mount host folders into the server container,
    make sure that user can write to them. For more information, see
    [Platform, Configuration & Security](/v2.1.x/deployment/upgrade/breaking-changes/platform-and-security#docker-images-are-distroless).
    </Note>
  </Step>
  <Step title="Start the Deployment">
    Start the Docker Compose service:

    ```bash
    docker compose -f docker-compose.yml up -d
    ```
  </Step>
</Steps>
