#### Source Config

- **dbtUpdateDescriptions**: Configuration to update the description from dbt or not. If set to true, descriptions from dbt will override the already present descriptions on the entity. For more details visit [here](/connectors/database/dbt/ingest-dbt-descriptions).
- **dbtUpdateOwners**: Configuration to update the owner from dbt or not. If set to true, owners from dbt will override the already present owners on the entity. For more details visit [here](/connectors/database/dbt/ingest-dbt-owner).
- **includeTags**: Set to `true` or `false` to ingest tags from dbt. Default is `true`.
- **dbtClassificationName**: Custom OpenMetadata Classification name for dbt tags.
- **catalogMapping**: Map of database names in the dbt manifest to the database names they are ingested under in OpenMetadata. Use it when the name dbt writes into the manifest differs from the name the connector ingested. Keys are matched ignoring case. For more information, see [Map dbt Catalog Names to OpenMetadata Databases](/connectors/database/dbt/ingest-dbt-lineage#map-dbt-catalog-names-to-openmetadata-databases).
- **databaseFilterPattern**, **schemaFilterPattern**: Add filters to filter out models from the dbt manifest. Note that the filter supports regex as include or exclude. You can find examples [here](/connectors/ingestion/workflows/metadata/filter-patterns/database).
- **tableFilterPattern**: Add a filter to filter out models from the dbt manifest. Note that the filter supports regex as include or exclude. You can find examples [here](/connectors/ingestion/workflows/metadata/filter-patterns/table).
