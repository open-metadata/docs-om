```python
from metadata.sdk import Tables, configure
from metadata.generated.schema.api.data.createTable import CreateTableRequest
from metadata.generated.schema.entity.data.table import Column, DataType

# The host must end with /api
configure(host="http://localhost:8585/api", jwt_token="your-jwt-token")

# Create
table = Tables.create(
    CreateTableRequest(
        name="customers",
        databaseSchema="mysql-prod.analytics.public",
        columns=[Column(name="id", dataType=DataType.BIGINT)],
    )
)

print(table.fullyQualifiedName.root)

# Update
table.description = "Customer master table"
table = Tables.update(table)

# Delete
Tables.delete(table.id)
```

Fields such as `name`, `id` and `fullyQualifiedName` are wrapper objects. Use `.root` to get the plain value, for example `table.fullyQualifiedName.root`.

You can also call `configure()` with no arguments. It reads `OPENMETADATA_HOST` and `OPENMETADATA_JWT_TOKEN` from your environment.
