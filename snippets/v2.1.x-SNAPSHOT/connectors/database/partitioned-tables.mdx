## Partitioned Tables

Starting in OpenMetadata 2.0.3, automatically detected BigQuery time-unit and ingestion-time partitions use the following profiling windows:

| Partition granularity | Default window |
| --- | --- |
| Hour | 24 hours |
| Day | 3 days |
| Month | 35 days |
| Year | 370 days |
| Unknown or unspecified | 3 days |

Explicit table-level partition settings override these defaults. Integer-range and value-based partitions do not use these time windows.

## Resolution

If a partition filter returns no sample rows, the ingestion logs warn that the window may not cover the table's most recent data. Open the table's profiler configuration and widen the partition interval as needed. In the partition configuration, `partitionInterval` sets the size and `partitionIntervalUnit` sets the unit, for example `30` and `DAY` for a 30-day window. A wider window can increase the amount of data scanned.
