To reindex the search:

1. Go to **Settings** > **Applications** and open **Search Indexing**.

    <img src="/public/images/how-to-guides/admin-guide/search-index/access-search-index.png" alt="Open the Search Indexing application" />

2. Select the **Schedule** tab.
3. Click **Run now** to start a reindex.

    <img src="/public/images/how-to-guides/admin-guide/search-index/search-index-run.png" alt="Run the Search Indexing application now" />

<Note>
 Starting with 2.0, every reindex rebuilds the search indexes from scratch, so no **Recreate Indexes** option exists. Running the app is enough.
 </Note>

To limit the run to specific entities:

1. Open the **Configuration** tab.
2. Edit the **Entities** field. It defaults to `All`. For more information, see [Entities](#entities).
3. Save the configuration.
4. Return to the **Schedule** tab.
5. Click **Run now**.
