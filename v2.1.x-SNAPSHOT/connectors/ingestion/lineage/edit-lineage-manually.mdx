# Edit Data Lineage Manually

Edit lineage to provide a richer understanding of the provenance of data. On an asset's **Lineage** tab, use the **Lineage options** menu on a node to add an upstream or downstream table, pipeline, or dashboard. Use the same menu on a column to link columns, and delete nodes or edges you no longer need.

For the full steps, see [How to Manually Add or Edit Lineage](/v2.1.x-SNAPSHOT/how-to-guides/data-lineage/manual).
