## Requirements

OpenMetadata connects to Tableau Server or Tableau Cloud through the Tableau REST API and the Tableau Metadata API.

- **Tableau Server or Tableau Cloud**: OpenMetadata must be able to reach it and authenticate with a username and password or a personal access token.
- **Metadata API enabled**: Required for lineage. Without it, metadata and run status still ingest, but OpenMetadata draws no lineage edges. For more information, see [Start the Metadata API](https://help.tableau.com/current/api/metadata_api/en-us/docs/meta_api_start.html).
- **Permissions**: The user needs permission to list flows and flow runs, and to query the Metadata API for lineage. Users who are not administrators see only the runs of flows they can view.
- **Tableau Prep Conductor**: Flows can run manually without Data Management, but scheduled flow runs need [Tableau Prep Conductor](https://help.tableau.com/current/prep/en-us/prep_conductor_overview.htm).
- **Site administrator for extract refresh status**: Tableau answers extract refresh job queries only for server and site administrators. Other users still get extract refresh pipelines for the refresh tasks they own, but without run status.

### Lineage

The connector reads lineage from the Tableau Metadata API:

- **Input to output lineage**: Each table or published data source a flow reads is linked to the tables or published data sources it writes, with the flow shown on the lineage edge.
- **Flow to flow lineage**: A flow is linked to the flows that consume its output. Only direct consumers are linked.
- **Extract refresh lineage**: An extract refresh pipeline is linked to the published data source or workbook data model it refreshes.

OpenMetadata resolves tables against the database services already in your instance. To restrict which services OpenMetadata searches, set **Database Service Names List** under **Lineage Information** in the metadata agent. Without it, OpenMetadata searches every database service and accepts only a single match, so a same-named table in another service never gets an edge.

Published data sources and workbook extracts resolve to the data models created by the [Tableau dashboard connector](/v2.1.x-SNAPSHOT/connectors/dashboard/tableau), so run the dashboard connector first.

<Note>
**Note**: Column-level lineage is not available for Tableau Pipeline.
</Note>

## Metadata Ingestion
All connectors are defined as JSON Schemas.
See the [Tableau Pipeline connection JSON Schema](https://github.com/open-metadata/OpenMetadata/blob/main/openmetadata-spec/src/main/resources/json/schema/entity/services/connections/pipeline/tableauPipelineConnection.json) for the full set of properties.
To create and run a metadata ingestion workflow, create a YAML configuration. The configuration connects to the source, processes entities if needed, and reaches the OpenMetadata server.
The workflow is modeled around the following
[JSON Schema](https://github.com/open-metadata/OpenMetadata/blob/main/openmetadata-spec/src/main/resources/json/schema/metadataIngestion/workflow.json).

**hostPort**: Tableau Server URL.

<ContentSection id={3} title="authType" lines="8-13">

**authType**: Choose one authentication method.
- **Basic authentication**: `username` and `password` used to sign in to Tableau.
- **Access token authentication**: `personalAccessTokenName` and `personalAccessTokenSecret`. For more information, see [Personal Access Tokens](https://help.tableau.com/current/server/en-us/security_personal_access_tokens.htm).

</ContentSection>

<ContentSection id={4} title="siteName and apiVersion" lines="14-15">

**siteName**: Optional Tableau site to ingest. Leave blank for the default site.

**apiVersion**: Optional Tableau REST API version. If not provided, OpenMetadata uses the version reported by the Tableau server.

</ContentSection>

<ContentSection id={5} title="numberOfStatus and includeExtractRefreshes" lines="16-17">

**numberOfStatus**: Number of recent runs to fetch per flow or extract refresh. The default is `10`, and the range is `1` to `100`.

**includeExtractRefreshes**: Ingest the extract refresh tasks of published data sources and workbooks as pipelines, with their refresh jobs as pipeline status. On by default. Reading refresh job history requires a site administrator.

</ContentSection>

<ContentSection id={6} title="verifySSL and sslConfig" lines="18-20">

**verifySSL**: Client SSL verification mode: `no-ssl` (default), `ignore`, or `validate`.

**sslConfig**: CA certificate, and for mutual TLS the client certificate and key, used when `verifySSL` is `validate`.

</ContentSection>

<ContentSection id={7} title="pipelineFilterPattern" lines="21-25">

**pipelineFilterPattern**: Regular expressions to include or exclude pipelines by name. This matches the flow name, or `<data source or workbook name> extract refresh` for extract refresh pipelines.

</ContentSection>

<CodePanel fileName="tableaupipeline_config.yaml">

```yaml
source:
  type: tableaupipeline
  serviceName: local_tableau_pipeline
  serviceConnection:
    config:
      type: TableauPipeline
      hostPort: <hostPort>  # REQUIRED - Tableau Server URL
      authType:  # REQUIRED - choose one method
        username: <username>
        password: <password>
        # # or, for access token authentication, replace username and password with:
        # personalAccessTokenName: <token name>
        # personalAccessTokenSecret: <token secret>
      # siteName: <site>
      # apiVersion: <version>
      # numberOfStatus: 10
      # includeExtractRefreshes: true
      # verifySSL: no-ssl
      # sslConfig:
      #   caCertificate: <ca certificate>
      # pipelineFilterPattern:
      #   includes:
      #     - <pipeline name>
      #   excludes:
      #     - <pipeline name>
```
