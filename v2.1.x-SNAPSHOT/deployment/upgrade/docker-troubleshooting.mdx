# Docker Upgrade Troubleshooting

## Permission Denied When Running `metadata openmetadata-imports-migration`

If you get a `Permission Denied` error when you run `metadata openmetadata-imports-migration --change-config-file-path`, you might need to change the permissions on the `/opt/airflow/dags` folder.

Open a shell in the ingestion container and check the permissions on the folder:

```bash
ls -l /opt/airflow
ls -l /opt/airflow/dags
```

Both the `dags` folder and the files inside it should be owned by `airflow:root`. If they are not, run:

```bash
chown -R airflow:root /opt/airflow/dags
```

## Broken Directed Acyclic Graphs (DAGs) Can't Load the Config File: Permission Denied

You might need to change the permissions on the `/opt/airflow/dag_generated_config` folder.

Open a shell in the ingestion container and check the permissions on the folder:

```bash
ls -l /opt/airflow
ls -l /opt/airflow/dag_generated_config
```

Both the `dag_generated_config` folder and the files inside it should be owned by `airflow:root`. If they are not, run:

```bash
chown -R airflow:root /opt/airflow/dag_generated_config
```
