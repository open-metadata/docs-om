## MCP Server

The MCP endpoint and its OAuth routes are served under the base path, for example `https://your-host/openmetadata/mcp`. Set the **MCP base URL** in the MCP Server application settings to the external URL that includes the base path, for example `https://your-host/openmetadata`. A trailing slash is ignored. If the base URL is missing the base path, the server logs a warning at startup.

The server answers `https://your-host/openmetadata/mcp/.well-known/oauth-authorization-server`, `https://your-host/openmetadata/mcp/.well-known/openid-configuration`, and `https://your-host/openmetadata/mcp/.well-known/oauth-protected-resource`. Clients that look only for `https://your-host/.well-known/...` at the host root need a reverse proxy route that forwards those requests to OpenMetadata.
