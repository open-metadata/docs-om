# How to Manually Add or Edit Lineage

OpenMetadata's no-code lineage editor lets you add and remove lineage directly from an asset's **Lineage** tab. Link tables, topics, dashboards, ML models, containers, and pipelines, and connect individual columns to build a complete picture of how your data flows.

You can edit both table-level and column-level lineage manually. This is useful for capturing relationships that ingestion doesn't automatically detect.

<Note>
You need edit permission on the asset to see the editing menus.
</Note>

## Edit a Lineage

Build lineage by adding upstream and downstream assets from the node menu.

### Step 1: Open the Lineage Tab

Navigate to the data asset you want to use as the starting point.

1. Go to your database service and open a table.
2. On the table details page, click the **Lineage** tab.
3. On a node, open the **Lineage options** menu.

<img src="/public/images/how-to-guides/lineage/lineage-node-menu.png" alt="Lineage options menu on a node with Edit Upstream, Edit Downstream, and Delete" />

### Step 2: Add an Upstream or Downstream Asset

Select the data asset you want to link as an upstream or downstream node.

1. In the **Lineage options** menu, select **Edit Upstream** or **Edit Downstream**. A panel slides out with the current asset and the new asset to add.

    <img src="/public/images/how-to-guides/lineage/lineage-add-upstream-panel.png" alt="Add Upstream panel with the Select type field and the Cancel and Add buttons" />

2. In **Select type**, choose the type of asset to connect, such as table, topic, dashboard, ML model, container, or pipeline. The list shows how many assets of each type exist.

    <img src="/public/images/how-to-guides/lineage/lineage-select-type.png" alt="Select type list with Tables, Dashboards, Charts, Stored Procedures, Topics, and ML Models" />

3. In **Search Asset**, search for the specific asset and select it. The list shows how many assets match, for example "Showing 10 of 1616 assets".

    <img src="/public/images/how-to-guides/lineage/lineage-search-asset.png" alt="Search Asset list showing 10 of 1616 assets with the asset name and path" />

4. Click **Add** to create the lineage connection. Click **Cancel** to close the panel without saving. The selected asset shows as the **New Upstream** at the top of the panel.

    <img src="/public/images/how-to-guides/lineage/lineage-selected-asset-add.png" alt="Add Upstream panel with the selected asset as New Upstream and the Cancel and Add buttons" />

The new asset appears on the graph with an edge to the current asset.

<img src="/public/images/how-to-guides/lineage/lineage-upstream-added.png" alt="Lineage graph with the new upstream asset highlighted and connected to the current asset" />

### Step 3: Add Column-Level Lineage

Link individual columns to trace field-level dependencies.

1. Show the columns on the node, either by expanding the node or by turning on the **Column** layer under **Layers**.
2. On the column, open the **Lineage options** menu and select **Edit Upstream** or **Edit Downstream**.
3. In the panel, select the asset in **Select Asset**, and use **Select Column** to pick the matching column. The asset must already be on the graph.
4. Click **Add**.

For more information, see [Column-Level Lineage](/v2.1.x-SNAPSHOT/how-to-guides/data-lineage/column).

<img src="/public/images/how-to-guides/lineage/lineage-column-picker.png" alt="Add Upstream panel for a column with the Select Asset list" />

## Remove or Edit Lineage

Remove assets and connections, or change the details of an edge, from the same **Lineage** tab.

### Remove an Asset

Delete a node and the lineage edges shown with it.

1. On the node, open the **Lineage options** menu.
2. Select **Delete**.
3. Confirm the removal in the dialog.

<Note>
The asset you started from has no **Delete** option. Temporary tables have no menu.
</Note>

### Edit or Remove an Edge

Open the edge details to update the pipeline or remove the connection.

1. Click the edge to open its details drawer.
2. Open the **Actions** menu.
3. Select **Edit Pipeline** to change the pipeline for the edge, or **Delete** to remove the edge. Confirm the deletion.

Edges that touch a temporary table are read-only.

### Use the Keyboard

Select a node or an edge, then press **Delete** or **Backspace** to remove it. The starting asset can't be deleted.
