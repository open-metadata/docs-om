# Overview of Data Contracts

OpenMetadata is a centralized, active metadata repository where all your data resides. In any organization, it's important to keep data consumers aligned with data producers. As more teams adopt the platform, a data mesh architecture with OpenMetadata Data Contracts can automatically validate schema, semantics, and data quality. This enforces SLAs across departments and domains.

Data Contracts are available for tables, topics, API endpoints, dashboards, pipelines, data products, and most other data assets. With a Data Contract, you can:

- Set the expected schema structure of an asset.
- Define its semantics — for example, ensuring that a table has a description field or an owner assigned. For more information, see [Data Ownership](https://docs.open-metadata.org/latest/how-to-guides/guide-for-data-users/data-ownership).
- Assign data quality tests.
- Record SLA, security, and terms of use.
- Track the contract's execution history over time.

A data product's contract also applies to the assets in it.
