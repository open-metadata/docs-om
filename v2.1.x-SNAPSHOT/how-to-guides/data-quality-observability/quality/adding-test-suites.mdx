# Adding Test Suites Through the UI
Test Suites are logical container allowing you to group related Test Cases together from different tables. This is a great way to group related test cases together and set a single alert for test case failure.

<Note>
**Note**: you will need to make sure you have the right permission in OpenMetadata to create a test.
</Note>

1. In the left navigation bar, select **Observability** > **Data Quality**.

    <img src="/public/images/features/ingestion/workflows/data-quality/access-data-quality.png" alt="Access data quality" />

2. Click the **Test Suites** tab.

    <img src="/public/images/features/ingestion/workflows/data-quality/test-suites-tab.png" alt="Test Suites tab" />

3. Click **Add a Bundle Suite**.

    <img src="/public/images/features/ingestion/workflows/data-quality/select-bundle-suite.png" alt="Click Add a Bundle Suite" />

4. Fill in the following details:
    - Enter a unique descriptive **Name**.
    - (Optional): Add **Description**.
    - Search and select the test cases. In OpenMetadata 2.0.3 and later, **Select All** adds only the test cases matching the active filters.

    <img src="/public/images/features/ingestion/workflows/data-quality/test-suite-details.png" alt="Test Suite details" />

After creating a suite, use the search field in its details view to find a test case.

Test cases are identified by their fully qualified names, which include the table or column they test. The same short test-case name can appear under different entities.
