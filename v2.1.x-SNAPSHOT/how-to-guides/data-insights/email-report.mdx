# Configure the Data Insights Report

Once the data insights ingestion has been set up, you can proceed to configure the email report for Data Insights.

- Navigate to **Settings** > **Features** > **Applications**, click **Browse Apps**, select the **Data Insights Report** application, and click **Install**.

<img src="/public/images/how-to-guides/insights/dir-marketplace.png" alt="Data Insights Report application page with the Install button" />

- On the **Details** step, review the **Authorize** screen and click **Next**.

<img src="/public/images/how-to-guides/insights/dir-install-details.png" alt="Install wizard Details step for the Data Insights Report" />

- On the **Configure** step, choose who receives the report. Turn **Send To Admins** and **Send To Teams** on or off, then click **Next**.

<img src="/public/images/how-to-guides/insights/dir-install-configure.png" alt="Configure step with the Send To Admins and Send To Teams switches" />

- On the **Schedule** step, select **Schedule** to send the report repeatedly or **On Demand** to send it once. For a schedule, set the **Day** and the **Time**. The frequency is **Weekly**. Click **Install**.

<img src="/public/images/how-to-guides/insights/dir-install-schedule.png" alt="Install wizard Schedule step for the Data Insights Report" />

- The Data Insights Report has been configured successfully.

<img src="/public/images/how-to-guides/insights/dir5.png" alt="Configured the Data Insights Report" />

- By clicking on **Configure** You can change the schedule for the data insights report. You can also change who receives the report (Admins/Teams). You can also view the **History** on when the report was last sent.

<img src="/public/images/how-to-guides/insights/dir6.png" alt="Data Insights Report" />
