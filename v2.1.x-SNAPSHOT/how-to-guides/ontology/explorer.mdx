# Ontology Explorer

The **Ontology Explorer** shows the terms of every glossary and the typed relations between them as one graph. Use it to see how your business vocabulary connects across glossaries, and which tables, columns, and metrics each term describes.

<Note>

**Note**: The Ontology Explorer is in **Beta**. It is read-only. To author native ontologies — concepts, properties, constraints, releases, and reviews — in a visual workspace, use [Ontology Studio](https://docs.getcollate.io/ai-2-0/how-to-guides/ontology/studio), available in Collate. In OpenMetadata you can author ontologies through the [Ontology API](/v2.1.x-SNAPSHOT/how-to-guides/ontology/api).

</Note>

Open it from **Govern** > **Ontology Explorer** in the left navigation, or go directly to `/governance/ontology`.

## The Header

The header shows the page title, a **Beta** badge, and a summary of the graph:

| Count | Meaning |
|---|---|
| **Terms** | Glossary terms in the graph. |
| **Relations** | Typed relations between those terms. |
| **Isolated** | Terms with no relation to any other term. |

## Model View

**Model** is the default view. It draws each term as a node and each relation as an edge, labeled with its relation type. Terms from the same glossary share a color, and isolated terms are laid out below the connected ones.

- **Find a concept**: Type a term name to highlight it in the graph.
- **Canvas controls**: In the lower-left corner, fit the graph to the screen, zoom in, zoom out, and refresh.

## Data View

**Data** shows the data layer: each term as a card listing the data assets linked to it — tables, columns, and metrics — with each asset's type. Relations between terms are drawn between their cards, and a legend names each relation style, such as **Related to**, **Parent of**, and **Antonym**.

- A card lists the first few assets. Select **Show more** to expand it.
- When more terms exist than fit on the canvas, select **Load more** to add them.

Assets reach this view through the glossary terms applied to them. To link an asset, add the glossary term to the table, column, or metric.

## Change the Model

The Ontology Explorer doesn't edit anything. To change what it shows:

- **Add or remove a relation**: Open the glossary term and edit its related terms. For more information, see [Relationship Types](/v2.1.x-SNAPSHOT/how-to-guides/data-governance/ontology/relationship-types).
- **Link a data asset**: Apply the glossary term to the asset.

## The Same Graph for One Glossary

Each glossary and glossary term page has a **Relations Graph** tab. It shows the same graph scoped to that glossary or term, so you can explore one part of the vocabulary without the rest.
