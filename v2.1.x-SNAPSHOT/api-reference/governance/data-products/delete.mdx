# Delete a Data Product

Delete a data product by ID or fully qualified name. Deleting a data product is permanent. A deleted data product can't be restored.

## Delete by ID

<ParamField path="id" type="string" required>
  UUID of the data product to delete.
</ParamField>

<ParamField query="recursive" type="boolean" default="false">
  Recursively delete child entities.
</ParamField>

<ParamField query="hardDelete" type="boolean" default="false">
  Not needed. A deleted data product is always permanently deleted, with or without this option.
</ParamField>

## Delete by Name

Use `DELETE /v1/dataProducts/name/{fqn}` to delete by fully qualified name.

<ParamField path="fqn" type="string" required>
  Fully qualified name of the data product (e.g., `CustomerInsights`).
</ParamField>

<ParamField query="recursive" type="boolean" default="false">
  Recursively delete child entities.
</ParamField>

<ParamField query="hardDelete" type="boolean" default="false">
  Not needed. A deleted data product is always permanently deleted, with or without this option.
</ParamField>

<RequestExample dropdown>
```python DELETE /v1/dataProducts/{id}
from metadata.sdk import configure
from metadata.sdk.entities import DataProducts

configure(
    host="https://your-company.open-metadata.org/api",
    jwt_token="your-jwt-token"
)

# Delete by ID
DataProducts.delete("b1839f98-f046-5f35-bdef-20f9b3395cb2")

# Delete by ID with options
DataProducts.delete(
    "b1839f98-f046-5f35-bdef-20f9b3395cb2",
    hard_delete=True
)

# Delete by name
DataProducts.delete(DataProducts.retrieve_by_name("CustomerInsights").id)
```

```java DELETE /v1/dataProducts/{id}
import java.util.Map;

// client is an initialized OpenMetadataClient.
var id = "b1839f98-f046-5f35-bdef-20f9b3395cb2";

// Delete (permanent)
client.dataProducts().delete(id);

// Delete by name: look up the ID first
var dataProduct = client.dataProducts().getByName("CustomerInsights");
client.dataProducts().delete(dataProduct.getId().toString());
```

```bash DELETE /v1/dataProducts/{id}
# Delete by ID
curl -X DELETE "{base_url}/api/v1/dataProducts/b1839f98-f046-5f35-bdef-20f9b3395cb2" \
  -H "Authorization: Bearer {access_token}"

# Delete with options
curl -X DELETE "{base_url}/api/v1/dataProducts/b1839f98-f046-5f35-bdef-20f9b3395cb2?hardDelete=true" \
  -H "Authorization: Bearer {access_token}"

# Delete by name
curl -X DELETE "{base_url}/api/v1/dataProducts/name/CustomerInsights" \
  -H "Authorization: Bearer {access_token}"
```
</RequestExample>

---

## Returns

Returns `200` with no content. The data product is permanently deleted and can't be restored.

---

## Error Handling

| Code | Error Type | Description |
|------|-----------|-------------|
| `401` | `UNAUTHORIZED` | Invalid or missing authentication token |
| `403` | `FORBIDDEN` | User lacks permission to delete this data product |
| `404` | `NOT_FOUND` | Data product with given ID or FQN does not exist |
