# Followers & Votes

Manage followers and votes for search index entities.

## Followers

### Add Follower

`PUT /v1/searchIndexes/{id}/followers`

<ParamField path="id" type="string" required>
  UUID of the search index.
</ParamField>

<ParamField body="id" type="string" required>
  UUID of the user to add as a follower (sent as request body string).
</ParamField>

### Remove Follower

`DELETE /v1/searchIndexes/{id}/followers/{userId}`

<ParamField path="id" type="string" required>
  UUID of the search index.
</ParamField>

<ParamField path="userId" type="string" required>
  UUID of the user to remove.
</ParamField>

## Votes

### Add or Update Vote

`PUT /v1/searchIndexes/{id}/vote`

<ParamField path="id" type="string" required>
  UUID of the search index.
</ParamField>

<ParamField body="updatedVoteType" type="string" required>
  Vote type: `votedUp`, `votedDown`, or `unVoted`.
</ParamField>

```python PUT /v1/searchIndexes/{id}/followers
from metadata.sdk import client, configure
from metadata.sdk.entities import SearchIndexes

configure(
    host="https://your-company.open-metadata.org/api",
    jwt_token="your-jwt-token"
)
rest = client().ometa.client

si_id = "f5b0fa81-f241-4508-9219-dae31dcced18"
user_id = "user-uuid-here"

# Add a follower
si = SearchIndexes.add_followers(si_id, [user_id])
print(f"Followers: {len(si.followers.root)}")

# Remove a follower
si = SearchIndexes.remove_followers(si_id, [user_id])

# Add a vote
rest.put(f"/searchIndexes/{si_id}/vote", json={"updatedVoteType": "votedUp"})

# Remove a vote
rest.put(f"/searchIndexes/{si_id}/vote", json={"updatedVoteType": "unVoted"})
```

```java PUT /v1/searchIndexes/{id}/followers
import java.util.Map;
import java.util.UUID;
import org.openmetadata.sdk.network.HttpClient;
import org.openmetadata.sdk.network.HttpMethod;

// client is an initialized OpenMetadataClient.

HttpClient http = client.getHttpClient();

String siId = "f5b0fa81-f241-4508-9219-dae31dcced18";
UUID userId = UUID.fromString("b6f7a1e2-3c4d-4e5f-8a9b-0c1d2e3f4a5b");

// Add a follower
http.executeForString(HttpMethod.PUT, "/v1/searchIndexes/" + siId + "/followers", userId);

// Remove a follower
http.executeForString(HttpMethod.DELETE, "/v1/searchIndexes/" + siId + "/followers/" + userId, null);

// Add a vote
http.executeForString(HttpMethod.PUT, "/v1/searchIndexes/" + siId + "/vote", Map.of("updatedVoteType", "votedUp"));

// Remove a vote
http.executeForString(HttpMethod.PUT, "/v1/searchIndexes/" + siId + "/vote", Map.of("updatedVoteType", "unVoted"));
```
