# Pipeline Observability

Manage pipeline observability data for a table. This tracks which pipelines produce or consume the table and their execution status.

## Get Pipeline Observability

`GET /v1/tables/{id}/pipelineObservability`

<ParamField path="id" type="string" required>
  UUID of the table.
</ParamField>

## Add Pipeline Observability

`PUT /v1/tables/{id}/pipelineObservability`

<ParamField path="id" type="string" required>
  UUID of the table.
</ParamField>

The request body is a list. Each item describes one pipeline:

<ParamField body="pipeline" type="object" required>
  Reference to the pipeline. Include its `id` (UUID), `type` (`pipeline`), and `fullyQualifiedName`.
</ParamField>

<ParamField body="serviceType" type="string">
  Type of the pipeline service, such as `Airflow`.
</ParamField>

<ParamField body="scheduleInterval" type="string">
  Schedule of the pipeline, as a cron expression.
</ParamField>

<ParamField body="lastRunTime" type="integer">
  Unix timestamp (milliseconds) of the last pipeline run.
</ParamField>

<ParamField body="lastRunStatus" type="string">
  Status of the last pipeline run: `Successful`, `Failed`, `Pending`, `Skipped`.
</ParamField>

<ParamField body="averageRunTime" type="number">
  Average run time of the pipeline.
</ParamField>

```python GET /v1/tables/{id}/pipelineObservability
from metadata.sdk import configure, client
from metadata.sdk.entities import Pipelines

configure(
    host="https://your-company.open-metadata.org/api",
    jwt_token="your-jwt-token"
)

rest = client().ometa.client

table_id = "a1b2c3d4-e5f6-7890-abcd-ef1234567890"

# Add pipeline observability
pipeline = Pipelines.retrieve_by_name("airflow_prod.customer_etl")
rest.put(f"/tables/{table_id}/pipelineObservability", json=[{
    "pipeline": {
        "id": str(pipeline.id.root),
        "type": "pipeline",
        "fullyQualifiedName": "airflow_prod.customer_etl"
    },
    "serviceType": "Airflow",
    "scheduleInterval": "0 0 * * *",
    "lastRunTime": 1706745600000,
    "lastRunStatus": "Successful"
}])

# Get pipeline observability
observability = rest.get(f"/tables/{table_id}/pipelineObservability")
for item in observability:
    print(f"{item['pipeline']['fullyQualifiedName']}: {item['lastRunStatus']}")
```

```java GET /v1/tables/{id}/pipelineObservability
import java.util.List;
import org.openmetadata.schema.api.services.CreatePipelineService.PipelineServiceType;
import org.openmetadata.schema.entity.data.Pipeline;
import org.openmetadata.schema.type.PipelineObservability;

String tableId = "a1b2c3d4-e5f6-7890-abcd-ef1234567890";

// Get pipeline observability
List<PipelineObservability> observability = client.tables().getPipelineObservability(tableId);

// Add pipeline observability
Pipeline pipeline = client.pipelines().getByName("airflow_prod.customer_etl");

PipelineObservability item = new PipelineObservability()
    .withPipeline(pipeline.getEntityReference())
    .withServiceType(PipelineServiceType.Airflow)
    .withScheduleInterval("0 0 * * *")
    .withLastRunTime(1706745600000L)
    .withLastRunStatus(PipelineObservability.LastRunStatus.SUCCESSFUL);

client.tables().addPipelineObservability(tableId, List.of(item));
```

## Returns

**Get** returns a list with one item for each pipeline linked to the table.

**Add** returns the updated table.

## Response

<ResponseField name="pipeline" type="object">
  Reference to the pipeline, with its `id`, `type`, and `fullyQualifiedName`.
</ResponseField>

<ResponseField name="serviceType" type="string">
  Type of the pipeline service.
</ResponseField>

<ResponseField name="scheduleInterval" type="string">
  Schedule of the pipeline, as a cron expression.
</ResponseField>

<ResponseField name="lastRunTime" type="integer">
  Unix timestamp of the last run in milliseconds.
</ResponseField>

<ResponseField name="lastRunStatus" type="string">
  Status of the last run.
</ResponseField>

<ResponseField name="averageRunTime" type="number">
  Average run time of the pipeline.
</ResponseField>
