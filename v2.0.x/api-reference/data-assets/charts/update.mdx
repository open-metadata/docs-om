# Update a Chart

Create a chart or update it if it already exists, using `PUT /v1/charts` with the full request body. Send the complete definition, not just the fields you want to change. To change only some fields, use `PATCH` with a JSON Patch array and the `application/json-patch+json` content type, as shown in the PATCH examples below.

## Body Parameters

<ParamField body="name" type="string" required>
  Name of the chart. Must be unique within the parent dashboard service.
</ParamField>

<ParamField body="service" type="string" required>
  Fully qualified name of the parent DashboardService, for example `sample_superset`.
</ParamField>

<ParamField body="displayName" type="string">
  Human-readable display name for the chart.
</ParamField>

<ParamField body="description" type="string">
  Description of the chart in Markdown format.
</ParamField>

<ParamField body="chartType" type="string">
  Type of chart visualization: `Line`, `Bar`, `Area`, `Pie`, `Scatter`, `Table`, `Histogram`, `Other`.
</ParamField>

<ParamField body="sourceUrl" type="string">
  URL of the chart in the source system.
</ParamField>

<ParamField body="owners" type="array">
  Array of owner references (users or teams) to assign to the chart.

  <Expandable title="properties">
    <ParamField body="id" type="string">
      UUID of the owner entity.
    </ParamField>

    <ParamField body="type" type="string">
      Type of owner entity, for example `user`, `team`.
    </ParamField>

    <ParamField body="name" type="string">
      Name of the owner entity.
    </ParamField>
  </Expandable>
</ParamField>

<ParamField body="domains" type="array">
  Fully qualified names of the domains to assign for governance purposes.
</ParamField>

<ParamField body="tags" type="array">
  Array of classification tags to apply to the chart.

  <Expandable title="properties">
    <ParamField body="tagFQN" type="string" required>
      Fully qualified name of the tag.
    </ParamField>

    <ParamField body="labelType" type="string">
      Type of label, for example `Manual`, `Derived`, `Propagated`.
    </ParamField>

    <ParamField body="state" type="string">
      State of the tag, for example `Suggested`, `Confirmed`.
    </ParamField>
  </Expandable>
</ParamField>

<ParamField body="extension" type="object">
  Custom property values defined by your organization's metadata schema.
</ParamField>

<RequestExample dropdown>
```bash PUT /v1/charts
curl -X PUT "{base_url}/api/v1/charts" \
  -H "Authorization: Bearer {access_token}" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "114",
    "displayName": "# of Games That Hit 100k in Sales By Release Year",
    "service": "sample_superset",
    "description": "Bar chart showing games that hit 100k in sales by release year",
    "chartType": "Other",
    "sourceUrl": "http://localhost:808/explore/?slice_id=114"
  }'
```

```python PATCH /v1/charts/{id}
from metadata.sdk import configure
from metadata.sdk.entities import Charts

configure(
    host="https://your-company.open-metadata.org/api",
    jwt_token="your-jwt-token"
)

# Retrieve, modify, and update
chart = Charts.retrieve("2dde4b53-a577-424b-bbaa-18ac32eca8a9")
chart.description = "Updated: Bar chart showing top-selling games by release year"
chart.chartType = "Bar"
updated = Charts.update(chart)

if updated is None:
    print("No changes were applied")
else:
    print(f"Updated to version {updated.version.root}")
```

```java PATCH /v1/charts/{id}
import org.openmetadata.schema.entity.data.Chart;

// client is an initialized OpenMetadataClient.

// Retrieve, modify, and update
Chart chart = client.charts().get("2dde4b53-a577-424b-bbaa-18ac32eca8a9");
chart.setDescription("Updated: Bar chart showing top-selling games by release year");
Chart updated = client.charts().update("2dde4b53-a577-424b-bbaa-18ac32eca8a9", chart);
```

```bash PATCH /v1/charts/{id}
# Update by ID
curl -X PATCH "{base_url}/api/v1/charts/2dde4b53-a577-424b-bbaa-18ac32eca8a9" \
  -H "Authorization: Bearer {access_token}" \
  -H "Content-Type: application/json-patch+json" \
  -d '[
    {"op": "replace", "path": "/description", "value": "Updated: Bar chart showing top-selling games by release year"}
  ]'

# Update by name
curl -X PATCH "{base_url}/api/v1/charts/name/sample_superset.114" \
  -H "Authorization: Bearer {access_token}" \
  -H "Content-Type: application/json-patch+json" \
  -d '[
    {"op": "replace", "path": "/description", "value": "Updated: Bar chart showing top-selling games by release year"}
  ]'
```

## Returns

Returns the updated chart object with the new version number.

## Response

<ResponseField name="id" type="string">
  Unique identifier for the chart (UUID format).
</ResponseField>

<ResponseField name="name" type="string">
  Chart name.
</ResponseField>

<ResponseField name="fullyQualifiedName" type="string">
  Fully qualified name in format `service.chartName`.
</ResponseField>

<ResponseField name="description" type="string">
  Updated description.
</ResponseField>

<ResponseField name="version" type="number">
  Incremented version number.
</ResponseField>

## Error Handling

| Code | Error Type | Description |
|------|-----------|-------------|
| `400` | `BAD_REQUEST` | Invalid or malformed request body |
| `401` | `UNAUTHORIZED` | Invalid or missing authentication token |
| `403` | `FORBIDDEN` | User lacks permission to update this chart |
| `409` | `CONFLICT` | Concurrent modification detected |
