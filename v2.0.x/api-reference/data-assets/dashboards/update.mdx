# Update a Dashboard

Create a dashboard or update it if it already exists, using `PUT /v1/dashboards` with the full request body. Send the complete definition, not just the fields you want to change. To change only some fields, use `PATCH` with a JSON Patch array and the `application/json-patch+json` content type, as shown in the PATCH examples below.

## Body Parameters

<ParamField body="name" type="string" required>
  Name of the dashboard. Must be unique within the parent dashboard service.
</ParamField>

<ParamField body="service" type="string" required>
  Fully qualified name of the parent DashboardService, for example `sample_superset`.
</ParamField>

<ParamField body="displayName" type="string">
  Human-readable display name for the dashboard.
</ParamField>

<ParamField body="description" type="string">
  Description of the dashboard in Markdown format.
</ParamField>

<ParamField body="sourceUrl" type="string">
  URL of the dashboard in the source system.
</ParamField>

<ParamField body="charts" type="array">
  Array of chart fully qualified names to associate with the dashboard.
</ParamField>

<ParamField body="owners" type="array">
  Array of owner references (users or teams) to assign to the dashboard.

  <Expandable title="properties">
    <ParamField body="id" type="string">
      UUID of the owner entity.
    </ParamField>

    <ParamField body="type" type="string">
      Type of owner entity, for example `user`, `team`.
    </ParamField>

    <ParamField body="name" type="string">
      Name of the owner entity.
    </ParamField>
  </Expandable>
</ParamField>

<ParamField body="domains" type="array">
  Fully qualified names of the domains to assign for governance purposes.
</ParamField>

<ParamField body="tags" type="array">
  Array of classification tags to apply to the dashboard.

  <Expandable title="properties">
    <ParamField body="tagFQN" type="string" required>
      Fully qualified name of the tag.
    </ParamField>

    <ParamField body="labelType" type="string">
      Type of label, for example `Manual`, `Derived`, `Propagated`.
    </ParamField>

    <ParamField body="state" type="string">
      State of the tag, for example `Suggested`, `Confirmed`.
    </ParamField>
  </Expandable>
</ParamField>

<ParamField body="extension" type="object">
  Custom property values defined by your organization's metadata schema.
</ParamField>

<RequestExample dropdown>
```bash PUT /v1/dashboards
curl -X PUT "{base_url}/api/v1/dashboards" \
  -H "Authorization: Bearer {access_token}" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "10",
    "displayName": "deck.gl Demo",
    "service": "sample_superset",
    "description": "Dashboard showcasing deck.gl visualizations",
    "sourceUrl": "http://localhost:808/superset/dashboard/10/"
  }'
```

```python PATCH /v1/dashboards/{id}
from metadata.sdk import configure
from metadata.sdk.entities import Dashboards

configure(
    host="https://your-company.open-metadata.org/api",
    jwt_token="your-jwt-token"
)

# Retrieve, modify, and update
dashboard = Dashboards.retrieve("03fb5cc3-de48-423f-9926-8e192e5de59d")
dashboard.description = "Updated: deck.gl Demo dashboard with new visualizations"
dashboard.displayName = "deck.gl Demo v2"
updated = Dashboards.update(dashboard)

if updated is None:
    print("No changes were applied")
else:
    print(f"Updated to version {updated.version.root}")
```

```java PATCH /v1/dashboards/{id}
import org.openmetadata.schema.entity.data.Dashboard;

// client is an initialized OpenMetadataClient.

// Retrieve, modify, and update
Dashboard dashboard = client.dashboards().get("03fb5cc3-de48-423f-9926-8e192e5de59d");
dashboard.setDescription("Updated: deck.gl Demo dashboard with new visualizations");
Dashboard updated = client.dashboards().update("03fb5cc3-de48-423f-9926-8e192e5de59d", dashboard);
```

```bash PATCH /v1/dashboards/{id}
# Update by ID
curl -X PATCH "{base_url}/api/v1/dashboards/03fb5cc3-de48-423f-9926-8e192e5de59d" \
  -H "Authorization: Bearer {access_token}" \
  -H "Content-Type: application/json-patch+json" \
  -d '[
    {"op": "replace", "path": "/description", "value": "Updated: deck.gl Demo dashboard with new visualizations"}
  ]'

# Update by name
curl -X PATCH "{base_url}/api/v1/dashboards/name/sample_superset.10" \
  -H "Authorization: Bearer {access_token}" \
  -H "Content-Type: application/json-patch+json" \
  -d '[
    {"op": "replace", "path": "/description", "value": "Updated: deck.gl Demo dashboard with new visualizations"}
  ]'
```

## Returns

Returns the updated dashboard object with the new version number.

## Response

<ResponseField name="id" type="string">
  Unique identifier for the dashboard (UUID format).
</ResponseField>

<ResponseField name="name" type="string">
  Dashboard name.
</ResponseField>

<ResponseField name="fullyQualifiedName" type="string">
  Fully qualified name in format `service.dashboardName`.
</ResponseField>

<ResponseField name="description" type="string">
  Updated description.
</ResponseField>

<ResponseField name="version" type="number">
  Incremented version number.
</ResponseField>

## Error Handling

| Code | Error Type | Description |
|------|-----------|-------------|
| `400` | `BAD_REQUEST` | Invalid or malformed request body |
| `401` | `UNAUTHORIZED` | Invalid or missing authentication token |
| `403` | `FORBIDDEN` | User lacks permission to update this dashboard |
| `409` | `CONFLICT` | Concurrent modification detected |
