# Followers & Votes

Manage followers and votes for table entities. Followers receive notifications about changes. Votes help surface popular or important tables.

## Followers

### Add Follower

`PUT /v1/tables/{id}/followers`

<ParamField path="id" type="string" required>
  UUID of the table.
</ParamField>

<ParamField body="id" type="string" required>
  UUID of the user to add as a follower (sent as request body string).
</ParamField>

### Remove Follower

`DELETE /v1/tables/{id}/followers/{userId}`

<ParamField path="id" type="string" required>
  UUID of the table.
</ParamField>

<ParamField path="userId" type="string" required>
  UUID of the user to remove.
</ParamField>

## Votes

### Add or Update Vote

`PUT /v1/tables/{id}/vote`

<ParamField path="id" type="string" required>
  UUID of the table.
</ParamField>

<ParamField body="updatedVoteType" type="string" required>
  Vote type: `votedUp`, `votedDown`, or `unVoted`.
</ParamField>

```python PUT /v1/tables/{id}/followers
from metadata.sdk import configure, client
from metadata.sdk.entities import Tables

configure(
    host="https://your-company.open-metadata.org/api",
    jwt_token="your-jwt-token"
)

rest = client().ometa.client

table_id = "a1b2c3d4-e5f6-7890-abcd-ef1234567890"
user_id = "user-uuid-here"

# Add a follower
table = Tables.add_followers(table_id, [user_id])
print(f"Followers: {len(table.followers.root)}")

# Remove a follower
table = Tables.remove_followers(table_id, [user_id])

# Add a vote
rest.put(f"/tables/{table_id}/vote", json={"updatedVoteType": "votedUp"})

# Remove a vote
rest.put(f"/tables/{table_id}/vote", json={"updatedVoteType": "unVoted"})
```

```java PUT /v1/tables/{id}/followers
import java.util.Map;
import java.util.UUID;
import org.openmetadata.sdk.network.HttpMethod;

// client is an initialized OpenMetadataClient.

String tableId = "a1b2c3d4-e5f6-7890-abcd-ef1234567890";
String userId = "b6f7a1e2-3c4d-4e5f-8a9b-0c1d2e3f4a5b";

// Add a follower
client.getHttpClient().executeForString(
    HttpMethod.PUT,
    "/v1/tables/" + tableId + "/followers",
    UUID.fromString(userId)
);

// Remove a follower
client.getHttpClient().executeForString(
    HttpMethod.DELETE,
    "/v1/tables/" + tableId + "/followers/" + userId,
    null
);

// Add a vote
client.getHttpClient().executeForString(
    HttpMethod.PUT,
    "/v1/tables/" + tableId + "/vote",
    Map.of("updatedVoteType", "votedUp")
);

// Remove a vote
client.getHttpClient().executeForString(
    HttpMethod.PUT,
    "/v1/tables/" + tableId + "/vote",
    Map.of("updatedVoteType", "unVoted")
);
```
