# Test Case Results

Retrieve test case execution results or add new results programmatically. Each result includes a status, timestamp, and detailed result values.

## Get Test Case Results

<ParamField path="fqn" type="string" required>
  Fully qualified name (FQN) returned when creating the test case. URL-encode it when necessary.
</ParamField>

<ParamField query="startTs" type="integer">
  Start timestamp (epoch milliseconds) to filter results.
</ParamField>

<ParamField query="endTs" type="integer">
  End timestamp (epoch milliseconds) to filter results.
</ParamField>

## Add a Test Case Result

Use `POST /v1/dataQuality/testCases/testCaseResults/{fqn}` to add a new test result.

<ParamField path="fqn" type="string" required>
  Fully qualified name (FQN) returned when creating the test case. URL-encode it when necessary.
</ParamField>

### Body Parameters

<ParamField body="timestamp" type="integer" required>
  Epoch timestamp (milliseconds) of the test execution.
</ParamField>

<ParamField body="testCaseStatus" type="string" required>
  Status of the test execution: `Success`, `Failed`, or `Aborted`.
</ParamField>

<ParamField body="result" type="string">
  Human-readable summary of the test result.
</ParamField>

<ParamField body="testResultValue" type="array" required>
  Array of detailed result values produced by the test.

  <Expandable title="properties">
    <ParamField body="name" type="string" required>
      Name of the result metric.
    </ParamField>

    <ParamField body="value" type="string" required>
      Value of the result metric.
    </ParamField>
  </Expandable>
</ParamField>

<RequestExample dropdown>
```bash GET /v1/dataQuality/testCases/testCaseResults/{fqn}
# Get test results
curl "{base_url}/api/v1/dataQuality/testCases/testCaseResults/sample_data.ecommerce_db.shopify.dim_address.shop_id.column_value_max_to_be_between" \
  -H "Authorization: Bearer {access_token}"

# Get results with time range
curl "{base_url}/api/v1/dataQuality/testCases/testCaseResults/sample_data.ecommerce_db.shopify.dim_address.shop_id.column_value_max_to_be_between?startTs=1769900000000&endTs=1769990000000" \
  -H "Authorization: Bearer {access_token}"

# Add a test result
curl -X POST "{base_url}/api/v1/dataQuality/testCases/testCaseResults/sample_data.ecommerce_db.shopify.dim_address.shop_id.column_value_max_to_be_between" \
  -H "Authorization: Bearer {access_token}" \
  -H "Content-Type: application/json" \
  -d '{
    "timestamp": 1769982800000,
    "testCaseStatus": "Success",
    "result": "Max value 42 is between 1 and 100",
    "testResultValue": [
      {"name": "maxValue", "value": "42"}
    ]
  }'
```
</RequestExample>

## Returns

**Get results** returns a list of test case result objects for the requested FQN and time range.

**Add result** returns the test case result object that was created.

## Test Case Status Values

| Status | Description |
|--------|-------------|
| `Success` | The test passed all assertions |
| `Failed` | The test failed one or more assertions |
| `Aborted` | The test was aborted due to an error or timeout |

---

## Error Handling

| Code | Error Type | Description |
|------|-----------|-------------|
| `401` | `UNAUTHORIZED` | Invalid or missing authentication token |
| `403` | `FORBIDDEN` | User lacks permission to view or add test results |
| `404` | `NOT_FOUND` | Test case with given FQN does not exist |
