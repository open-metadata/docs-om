# Create a Data Contract

Data contracts are available for tables, topics, API endpoints, dashboards, pipelines, data products, and most other data assets. For the full list and which sections each asset supports, see [Supported Assets](/v2.0.x/how-to-guides/data-contracts/spec#supported-assets).

This guide creates a contract for a table. The form shows only the tabs an asset supports:

| Asset | Form tabs |
|---|---|
| Table | Contract Details, Terms of Service, Schema, Semantics, Security, Quality, SLA |
| Topic, API Endpoint, Dashboard Data Model | Contract Details, Terms of Service, Schema, Semantics, Security, SLA |
| Data Product and other assets | Contract Details, Terms of Service, Semantics, Security, SLA |

Creating a contract requires the **Create** permission on data contracts. Editing or running one requires **Edit All** on the contract.

## Create a Contract in the UI

1. On the asset's page, select the **Contract** tab.
2. Select **Add Contract** > **Create Contract with UI**.

<img src="/public/images/how-to-guides/contracts/create1.png" alt="Adding a Data Contract to an OpenMetadata Table" />

3. On the **Contract Details** tab, enter a **Contract Title**. Optional: Add **Owners** and a **Description**.

<img src="/public/images/how-to-guides/contracts/create2.png" alt="Adding Contract Details" />

4. Optional: On the **Terms of Service** tab, describe how the data may be used.
5. On the **Schema** tab, select the columns the contract covers, or select all columns with the checkbox in the header. Only top-level columns can be selected.

<img src="/public/images/how-to-guides/contracts/create3.png" alt="Selecting a schema for an OpenMetadata Data Contract" />

6. On the **Semantics** tab, select **Add Semantics** and build a rule with a **Name**, a **Description**, and a **Rule**. The rule builder checks metadata such as owners, description, domain, data product, tags, glossary terms, tier, and status. Select **Add New Rule** to add more rules. Use each rule's switch to turn it on or off.

<img src="/public/images/how-to-guides/contracts/create4.png" alt="Adding rules to an OpenMetadata Data Contract" />

<img src="/public/images/how-to-guides/contracts/create5.png" alt="Adding more rules to an OpenMetadata Data Contract" />

7. Optional: On the **Security** tab, enter a **Data Classification**, and select **Add Policy** to record an **Access Policy**, its **Identities**, and **Row Filters**.
8. On the **Quality** tab, select the table's existing test cases, or select **Add Test** to create a new [data quality test](/v2.0.x/how-to-guides/data-quality-observability/quality/test).

<img src="/public/images/how-to-guides/contracts/create6.png" alt="Adding data quality tests to an OpenMetadata Data Contract" />

9. Optional: On the **SLA** tab, set the **Refresh Frequency**, **Max Latency**, **Availability Time**, **Retention**, and the **Column** that holds the refresh time.
10. Select **Save**.

In OpenMetadata 2.0.x, a contract created in the UI is saved as **Approved**. For what each section holds and which sections a run checks, see [Contract Sections](/v2.0.x/how-to-guides/data-contracts/spec#contract-sections).

## Run a Contract

To check the contract now, open the actions menu on the **Contract** tab and select **Run now**.

<img src="/public/images/how-to-guides/contracts/create7.png" alt="Running an OpenMetadata Data Contract" />

A run checks the schema, semantics, and quality sections. The **Data Contract Validation** application also runs every contract daily at midnight by default. The **Contract** tab shows the result of each section and an **Execution History** chart. For what each result means, see [Running a Contract](/v2.0.x/how-to-guides/data-contracts/spec#running-a-contract).

## Manage a Contract

The actions menu on the **Contract** tab has these options:

| Option | What it does |
|---|---|
| **Edit** | Opens the contract form. |
| **Run now** | Runs the contract. |
| **Import** | Imports a contract in the OpenMetadata YAML format. |
| **Import ODCS** | Imports an ODCS contract. See [ODCS Import and Export](/v2.0.x/how-to-guides/data-contracts/odcs). |
| **Export** | Downloads the contract as OpenMetadata YAML. |
| **Export as ODCS** | Downloads the contract as an ODCS v3.1.0 YAML file. |
| **Delete** | Permanently deletes the contract and its run history. |

Use the view switch next to the actions menu to see the contract as YAML.

## Import a Contract

To create a contract from a file instead of the form, select **Add Contract** > **Import OM** for an OpenMetadata YAML file, or **Add Contract** > **Import ODCS** for an ODCS file.

When the asset already has a contract, the import asks how to apply the file:

- **Merge with Existing**: Updates the fields the file sets and keeps the rest.
- **Replace Entire Contract**: Replaces the contract with the file.
