# Preferences

**Preferences** is the section of Settings where admins configure platform-wide behavior:

- How the interface looks
- How the platform sends email
- How search and lineage behave by default
- How the profiler computes metrics

Unlike Teams, Roles, or Services, none of these settings are scoped to a single team, connector, or asset. A change here takes effect for every user on the instance the next time they load the relevant page, so it's worth understanding what a setting does before changing it, not just where to find it.

## How to Access

Click the **Profile** icon and navigate to **Settings** > **Preferences**.

<img src="/public/images/how-to-guides/admin-guide/preferences/access-preference.png" alt="Navigate to Settings > Preferences" />

Every item under Preferences requires **Admin** access. Non-admin users don't see the Preferences menu at all, so if a teammate reports they can't find these settings, that's expected unless they've been made an admin.

## What's in Preferences

The table below lists every setting under Preferences, in the order it appears in the product, with a short description of what each one does and a link to the full guide.

| Setting | What it controls | Guide |
|:--- |:--- |:--- |
| **Theme** | Custom logo, monogram, favicon, and brand color palette | [Theme and Branding](/v2.0.x/how-to-guides/admin-guide/preferences/theme-and-branding) |
| **Email** | SMTP server used to send notification, invite, and alert emails | [Email](/v2.0.x/how-to-guides/admin-guide/preferences/email) |
| **OpenMetadata URL** | The base URL used to build links inside outgoing emails | [Email](/v2.0.x/how-to-guides/admin-guide/preferences/email#openmetadata-url) |
| **Login Configuration** | Failed login lockout and JWT session expiry | [Login Configuration](/v2.0.x/how-to-guides/admin-guide/preferences/login-configuration) |
| **Health Check** | Live status of the database, search index, migrations, and related dependencies | [Health Check](/v2.0.x/how-to-guides/admin-guide/preferences/health-check) |
| **Profiler Configuration** | Which profiler metrics run by default, per data type | [Profiler Configuration](/v2.0.x/how-to-guides/admin-guide/preferences/profiler-configuration) |
| **Search** | Search relevance, ranking, and per-asset-type field weighting | [Search Configuration Settings](/v2.0.x/how-to-guides/admin-guide/search-configuration-settings) |
| **Lineage** | Default upstream/downstream depth and lineage view mode | [Lineage](/v2.0.x/how-to-guides/admin-guide/preferences/lineage) |
| **Data Asset Rules** | Platform-wide metadata validation rules assets must satisfy | [Data Asset Rules](/v2.0.x/how-to-guides/admin-guide/data-asset-rules) |
| **Learning Resources** | In-product learning content shown to end users | [Learning Resources](/v2.0.x/how-to-guides/admin-guide/learning-resources) |

Custom Logo and Theme aren't separate settings. They're two panels on the same **Theme** page in the product. For more information about customizing your logo, favicon, and color palette, see [Theme and Branding](/v2.0.x/how-to-guides/admin-guide/preferences/theme-and-branding).
