# Export Lineage

You can export the lineage information for a data asset as a CSV, PNG, or PDF file, which makes it easier to do advanced analysis on the lineage information or share a visual snapshot.

**To export the lineage:**
1. Navigate to the **Explore** page and select a data asset.
2. Click the **Lineage** tab.
3. Click the **Export** icon, and do the following:

    <img src="/public/images/features/ingestion/lineage/export-lineage.png" alt="Export Lineage" />

    - Select an **Export Type** from *CSV*, *PNG*, or *PDF*.

        <Note>
        **Note**: **PNG** and **PDF** export are currently in **Beta**.
        </Note>

    - Edit the **File Name**.

        <img src="/public/images/features/ingestion/lineage/export-detail.png" alt="Export Details" />

4. Click **Export**.
